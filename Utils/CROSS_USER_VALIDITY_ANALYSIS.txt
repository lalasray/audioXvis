TIER 1: FEATURES THAT ARE UNIVERSAL & CROSS-USER VALID (95-100% valid)
===============================================================================

1. PITCH/F0 CONTOUR (Importance: 10/10)
   ├─ Cross-User Valid: ✅ YES (95-100%)
   ├─ Why Universal:
   │  • Fundamental physics of vocal fold vibration applies to all humans
   │  • All voices have an F0 (even if different range)
   │  • Measures actual physical phenomenon
   │  • Works regardless of gender, age, accent
   │
   ├─ What VARIES between users:
   │  • F0 RANGE (male: 85-180 Hz, female: 165-255 Hz, children: higher)
   │  • F0 STABILITY (some people more stable than others)
   │  • Vibrato characteristics (some add vibrato, some don't)
   │  • Voice breaks/instability patterns
   │
   ├─ User Baseline Needed: YES
   │  • Establish each user's normal F0 range first
   │  • Compare variations within their range, not absolute values
   │
   └─ Interpretation Example:
      Speaker A (male): F0 = 120 Hz → NORMAL ✓
      Speaker B (female): F0 = 120 Hz → ABNORMALLY LOW ✗
      Speaker B (female): F0 = 220 Hz → NORMAL ✓

   │  • But still interpretable across users

   │

      Speaker B (tight mouth): Blurry formants → Tense vowels ✓

   │  │  - Room acoustics
   │  │  - Speaker vocal volume
   │
   ├─ What VARIES between users:
   │  • ABSOLUTE RMS levels (very user/recording specific)
   │  • Energy envelope shape (more universal)
   │  • Dynamics range (some speakers 10dB range, others 30dB)
   │
   ├─ User Baseline Needed: YES - ESSENTIAL
   │  • Normalize against each speaker's baseline
   │  • Look at RELATIVE changes, not absolute values
   │  • Never compare raw RMS across different speakers or recordings
   │
   ├─ To Make Cross-User Valid:
   │  • Normalize: (RMS - speaker_min) / (speaker_max - speaker_min)
   │  • Or: Compare to speaker's average, not population average
   │
   └─ ❌ BAD: "Speaker A has RMS = 0.5, Speaker B has RMS = 0.3 → A is louder"
       ✅ GOOD: "Speaker A RMS increased 20% from baseline, Speaker B increased 15%"

PRACTICAL GUIDE: HOW TO USE ACROSS DIFFERENT USERS
================================================================================

SCENARIO 1: Comparing SAME FEATURE across DIFFERENT SPEAKERS
─────────────────────────────────────────────────────────────

❌ DON'T DO THIS:
   Speaker A RMS Energy = 0.5
   Speaker C RMS Energy = 0.3
   → "Speaker A louder"
   (Recording conditions differ!)

✅ DO THIS:
   Step 1: Establish each speaker's baseline
      Speaker A normal RMS = 0.4, range = 0.3-0.6
      Speaker C normal RMS = 0.25, range = 0.2-0.35
   
   Step 2: Compare deviations
      Speaker A current = 0.5 → +25% above baseline
      Speaker C current = 0.3 → +20% above baseline
      → Similar vocal effort levels


─────────────────────────────────────────────────────────────

SCENARIO 2: Comparing MULTIPLE FEATURES across SPEAKERS
────────────────────────────────────────────────────────

✅ BEST APPROACH:
   1. Use frequency-based features first (F0, mel-spec, chroma)
      → These are most cross-user stable
   
   2. Establish speaker baseline for energy/amplitude features
      → Then look at deviations
   
   3. Use normalized/delta versions
      → RMS delta, MFCC deltas, spectral changes


─────────────────────────────────────────────────────────────

SCENARIO 3: Building ML MODEL across MULTIPLE SPEAKERS
──────────────────────────────────────────────────────

✅ RECOMMENDED FEATURES:
   Priority 1 (Most Cross-User Compatible):
      • Pitch/F0
      • Mel-Spectrogram
      • MFCC (normalized)
      • Harmonic/Percussive ratio
   
   Priority 2 (With Normalization):
      • Spectral Contrast
      • Chroma
      • Spectral Centroid (normalized)
   
   ⚠️  AVOID raw/unnormalized:
      • Raw RMS Energy
      • Raw Waveform Amplitude
      • Raw Tempogram (without pace adjustment)

✅ NORMALIZATION TECHNIQUES:
   • Z-score: (X - mean) / std
   • Min-max: (X - min) / (max - min)
   • Speaker-specific baseline subtraction

KEY TAKEAWAYS
================================================================================

1. ✅ THE IMPORTANCE RANKING IS UNIVERSAL
   → Same top features matter for all speakers

2. ⚠️  THE INTERPRETATION CHANGES PER USER
   → F0 = 120 Hz means different things for male vs female

3. 🎯 FREQUENCY-BASED FEATURES (F0, Mel-Spec, MFCC) are most cross-user valid
   → Use these for comparing across speakers

4. 🚫 AMPLITUDE-BASED FEATURES (RMS, Waveform) need normalization
   → Don't compare raw values across speakers

5. 📊 ALWAYS ESTABLISH A BASELINE per speaker
   → Know their "normal" before detecting abnormality

6. 📈 LOOK AT CHANGES & PATTERNS, not absolute values
   → "x increased 20% for this speaker" better than "x = 0.5"

7. 🔄 FOR ML MODELS: Normalize all features
   → Use Z-score or min-max normalization
   → Makes features comparable across users
